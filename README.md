# Seguridad en videojuegos online

Trabajo Fin de Grado desarrollado en el Grado en Ingeniería Informática de la Universidad Autónoma de Madrid.

El proyecto analiza patrones de riesgo en videojuegos online mediante una metodología pasiva y no intrusiva. A partir de los resultados obtenidos, se desarrolló un laboratorio virtual aislado para reproducir y mitigar distintos escenarios de seguridad.

## Contenido

- Análisis de 10 videojuegos online.
- Laboratorio virtual aislado.
- Prueba de concepto de DOM-based XSS.
- Simulación de un ataque encadenado sobre la gestión de sesión.
- Implementación y validación de medidas de mitigación.

## Tecnologías

JavaScript · Node.js · HTML · CSS · VirtualBox · Burp Suite · Wireshark
